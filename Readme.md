# Endless HTML · 知识站

这里存放一系列**知识讲解类 HTML 学习页面**。

[Go site](https://serenyth.github.io/studys/)

## 关于内容

本仓库中的学习页面，内容均由 **AI 收集、整理后生成**。

流程大致是：

1. **收集** —— 由 AI 汇总某一主题的核心知识点、术语与脉络；
2. **整理** —— 对知识点进行结构化梳理，划分阶段与模块；
3. **生成** —— 最终产出为可直接打开的可视化学习 HTML 页面。

例如 **PacketFlow**（计算机网络可视化学习平台）就是通过 AI 制作的一个完整项目，包含动画、Canvas 与可交互模型。
