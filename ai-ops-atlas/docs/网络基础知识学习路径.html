学习路径 · 计算机网络

网络基础知识系统化学习路径

从零基础到具备独立组网与排障能力，按「分层模型 → 各层协议 → 设备与拓扑 → 安全 → 实战」的主线拆分为 8 个阶段。每个阶段给出学习目标、重点知识点、推荐学习顺序与实践任务，由浅入深、循序渐进。

8 个阶段由基础到进阶
约 10–12 周每天 1–2 小时
4 大核心IP 编址 / 传输层 / 应用层 / 安全
3 条主线理论 · 抓包 · 模拟器实操

阶段总览

先看全局，再逐层深入。建议严格按序号推进，后一阶段依赖前一阶段的基础。

01

网络入门与分层模型基础

打地基 · 建议 1 周 · 难度 ★☆☆☆☆

学习目标

  • 建立「网络是什么、为什么必须分层」的整体认知
  • 能准确说出 OSI 七层与 TCP/IP 四层每一层的职责
  • 能完整描述数据从发送端到接收端的封装与解封装过程
  • 认识带宽、时延、吞吐量、丢包率等基本性能指标

重点知识点

  • 网络分类：PAN / LAN / MAN / WAN 与互联网的组成
  • 协议与协议栈：为什么需要分层、分层带来的好处
  • OSI 七层模型：物理层、数据链路层、网络层、传输层、会话层、表示层、应用层
  • TCP/IP 四层模型：网络接口层、网络层、传输层、应用层，与 OSI 的对应关系
  • 数据封装：数据 → 段 → 包 → 帧 → 比特，以及 PDU 概念
  • 性能指标：带宽 vs 吞吐量、RTT、抖动、丢包率

推荐学习顺序

为什么要分层→ OSI 七层（口诀：物数网传会表应）→ TCP/IP 四层对照→ 封装与解封装→ 性能指标
实践任务：用 ping 访问一个网站，同时用 Wireshark 抓包，观察同一份数据在以太网帧、IP 包、ICMP 报文三个层次上的结构差异。
02

物理层与数据链路层基础

局域网如何工作 · 建议 1 周 · 难度 ★★☆☆☆

学习目标

  • 理解信号如何在物理介质中传输与编码
  • 掌握以太网帧结构与 MAC 地址的作用
  • 理解交换机如何基于 MAC 地址表转发数据
  • 理解 ARP 如何完成「IP 地址 → MAC 地址」的解析

重点知识点

  • 传输介质：双绞线（Cat5e/6/6a）、光纤（单模/多模）、无线
  • 信号基础：数字信号、编码与调制、单工/半双工/全双工
  • 以太网与帧：Ethernet II 帧结构、MTU、CRC 校验
  • MAC 地址：48 位、OUI、单播/组播/广播
  • 交换机原理：MAC 地址表、泛洪、转发、冲突域与广播域
  • VLAN 与 Trunk：802.1Q 标签、端口类型
  • STP 生成树：环路危害与冗余链路
  • ARP 协议：请求/应答、ARP 缓存、ARP 欺骗隐患

推荐学习顺序

传输介质与信号→ 以太网帧与 MAC→ 交换机工作原理→ VLAN / Trunk→ STP→ ARP
实践任务：在 Cisco Packet Tracer 中用两台交换机 + 四台主机搭建局域网，划分两个 VLAN 并配置 Trunk 互联；用 arp -a 观察 ARP 缓存表的变化。
03

网络层与 IP 编址核心

整个路径的重点与难点 · 建议 2 周 · 难度 ★★★★☆

学习目标

  • 熟练完成 IPv4 地址、子网掩码、网络地址与广播地址的计算
  • 能独立完成子网划分、VLSM 与 CIDR 聚合
  • 理解路由表结构与路由器逐跳转发的过程
  • 掌握 NAT 原理与 IPv6 基础，理解两者解决的核心问题

重点知识点

  • IPv4 地址：32 位结构、A/B/C/D/E 类、私有地址段、特殊地址
  • 子网掩码：网络位/主机位、可用主机数计算（2n−2）
  • 子网划分：等长子网、VLSM 变长子网、CIDR 无类域间路由与路由聚合
  • IP 报文头：TTL、协议号、标识/标志/片偏移、校验和
  • 路由原理：路由表、最长前缀匹配、默认路由、直连/静态/动态路由
  • 动态路由协议：RIP、OSPF、BGP 的定位与差异（先会用，再深入）
  • NAT / NAPT：私有地址上网、端口映射、静态与动态 NAT
  • ICMP：ping、traceroute 的原理与常见差错报文
  • IPv6：128 位地址、地址类型、与 IPv4 的迁移方案

推荐学习顺序

IP 地址与掩码→ 子网划分（大量手算）→ CIDR / VLSM→ IP 报文头→ 路由表与静态路由→ 动态路由 OSPF→ NAT→ IPv6
实践任务：① 手算 20 道子网划分题（把 192.168.10.0/24 按需求切成不同大小的子网）；② 在模拟器中配置两台路由器 + 三条静态路由，再用 OSPF 重做一遍并对比路由表；③ 用 tracert 观察数据包经过的每一跳。
04

传输层与端到端通信核心

可靠性从哪来 · 建议 1 周 · 难度 ★★★☆☆

学习目标

  • 深入理解 TCP 与 UDP 的本质差异及各自适用场景
  • 能画出并解释三次握手、四次挥手的完整状态变化
  • 理解 TCP 如何实现可靠传输、流量控制与拥塞控制
  • 熟悉端口与 Socket 概念及常见服务端口号

重点知识点

  • 端口与 Socket：源/目的端口、四元组、端口分类（知名/注册/动态）
  • TCP 报文头：序列号、确认号、标志位（SYN/ACK/FIN/RST/PSH）
  • 连接管理：三次握手、四次挥手、TIME_WAIT 与半关闭
  • 可靠传输：确认应答、超时重传、快重传、滑动窗口
  • 流量控制：接收窗口与零窗口探测
  • 拥塞控制：慢启动、拥塞避免、快恢复（AIMD）
  • UDP：无连接、无可靠性保证、头部仅 8 字节、适用场景（DNS/视频/游戏）
  • 常见端口：21 / 22 / 23 / 25 / 53 / 80 / 110 / 143 / 443 / 3389

推荐学习顺序

端口与 Socket→ TCP 报文头→ 三次握手 / 四次挥手→ 可靠传输机制→ 流量与拥塞控制→ UDP 对比
实践任务：用 Wireshark 抓一次完整的 TCP 会话（如打开一个网页），找到 SYN / SYN-ACK / ACK 三个包，跟踪一个 TCP 流的序号变化，并观察连接关闭时四次挥手的过程。
05

应用层协议族核心

最贴近日常开发与运维 · 建议 2 周 · 难度 ★★★☆☆

学习目标

  • 掌握 HTTP/HTTPS 的请求响应模型与 HTTPS 加密流程
  • 理解 DNS 的域名结构与递归/迭代解析过程
  • 掌握 DHCP 自动分配 IP 的完整交互流程
  • 能串联「输入网址到页面显示」的完整网络链路

重点知识点

  • HTTP：请求/响应模型、方法（GET/POST/PUT/DELETE）、状态码（2xx/3xx/4xx/5xx）、头部字段、Cookie 与 Session、连接复用
  • HTTP 版本演进：1.1 队头阻塞 → HTTP/2 多路复用 → HTTP/3 基于 QUIC
  • HTTPS 与 TLS：对称加密 + 非对称加密 + 哈希、数字证书与 CA、TLS 握手、证书链验证
  • DNS：域名层级结构、根/顶级/权威域名服务器、递归与迭代查询、记录类型（A / AAAA / CNAME / MX / NS / TXT / PTR）、缓存与 TTL、DoH/DoT
  • DHCP：DORA 四步（Discover / Offer / Request / Ack）、租约与续租、DHCP 中继
  • 其他常用协议：FTP/SFTP、SMTP/POP3/IMAP、SSH、Telnet、NTP、SNMP、WebSocket

推荐学习顺序

HTTP 基础→ HTTP 版本演进→ HTTPS / TLS→ DNS→ DHCP→ 其他协议→ 全链路串联
实践任务：① 用 curl -v 请求一个网站，逐行读懂请求头与响应头；② 用 nslookup / dig 查询同一域名的 A 记录与 CNAME 记录；③ 在浏览器开发者工具的 Security 面板查看证书链；④ 用 ipconfig /release 与 /renew 抓取一次 DHCP 的 DORA 过程。
06

网络设备与拓扑结构应用

把知识拼成一张真实的网 · 建议 1 周 · 难度 ★★☆☆☆

学习目标

  • 清楚每种网络设备工作在 OSI 的哪一层、解决什么问题
  • 理解常见拓扑结构的优缺点与适用场景
  • 能读懂并绘制一个中小型网络的拓扑图
  • 了解无线网络与广域网接入的基本方式

重点知识点

  • 设备与工作层次：网卡、中继器/集线器（L1）、交换机（L2）、路由器/三层交换机（L3）、防火墙、负载均衡器、代理服务器、无线 AP/AC
  • 拓扑结构：总线型、星型、环型、树型、网状、混合型 —— 可靠性、成本、扩展性对比
  • 层次化组网：接入层 / 汇聚层 / 核心层三层架构
  • 无线网络：802.11 系列标准、SSID、信道与干扰、WPA2/WPA3 加密
  • 广域网接入：PPPoE、专线、MPLS、SD-WAN 概览
  • 冗余与高可用：链路聚合、堆叠、VRRP 双机热备

推荐学习顺序

设备与工作层次→ 拓扑结构对比→ 三层网络架构→ 冗余与高可用→ 无线网络→ 广域网接入
实践任务：画出你所在家庭或公司的真实网络拓扑图，标注每个设备的型号、所在层次、IP 地址段与出口链路。
07

网络安全基础核心

知其攻，方能防 · 建议 2 周 · 难度 ★★★★☆

学习目标

  • 建立以 CIA 三要素为核心的网络安全认知框架
  • 理解对称加密、非对称加密、哈希与数字证书的配合方式
  • 掌握防火墙、IDS/IPS、VPN 等主要防护手段的定位
  • 能识别常见网络攻击的原理并说出对应防御措施

重点知识点

  • 安全模型：CIA 三要素（机密性、完整性、可用性）、威胁与脆弱性、最小权限原则
  • 密码学基础：对称加密（AES）、非对称加密（RSA/ECC）、哈希（SHA-256）、数字签名、PKI 与 CA 体系
  • 传输层安全：TLS/SSL 握手、证书验证、HTTPS 全流程回顾
  • 网络层安全：IPSec、VPN（站点到站点 / 远程接入）
  • 边界防护：防火墙（包过滤 / 状态检测 / 应用层）、IDS/IPS、WAF、DMZ
  • 身份与访问控制：AAA、802.1X、RADIUS、零信任思想
  • 常见攻击：DDoS、中间人攻击、ARP 欺骗、DNS 劫持、端口扫描、暴力破解、SQL 注入、XSS、钓鱼
  • 安全运维：日志与审计、漏洞管理、应急响应流程

推荐学习顺序

CIA 与威胁模型→ 加密与 PKI→ TLS 深入→ 防火墙与 VPN→ 身份认证→ 常见攻击与防御
实践任务：① 在授权范围内用 Nmap 扫描自己的实验网络，理解端口状态含义；② 用 Wireshark 观察一次未加密 HTTP 登录的明文风险；③ 用 openssl 命令查看一个网站的证书链并解读各字段。
08

进阶方向与实战进阶

从会用到会解决 · 建议 持续学习 · 难度 ★★★★★

学习目标

  • 形成一套可复用的分层排障方法论
  • 能独立用抓包工具定位真实网络问题
  • 了解网络自动化、云网络与容器网络的演进方向
  • 根据职业方向选择深耕领域（运维 / 安全 / 开发 / 云）

重点知识点

  • 排障方法论：自下而上 / 自上而下 / 分而治之、常见故障清单（不通、慢、丢包、间歇性）
  • 抓包分析：Wireshark 显示与捕获过滤器、TCP 流跟踪、专家信息
  • 性能优化：延迟与带宽分析、QoS、流量整形、CDN
  • 网络自动化：Python + Netmiko / Paramiko、Ansible、NETCONF / YANG
  • SDN：控制面与数据面分离、OpenFlow、VXLAN Overlay
  • 云网络：VPC、子网与路由表、安全组 / ACL、负载均衡、专线接入
  • 容器网络：Docker 网络模式、Kubernetes CNI、Service 与 Ingress
  • 前沿方向：IPv6 规模部署、Wi-Fi 6/7、5G、零信任架构、可观测性

推荐学习顺序

排障方法论→ 抓包实战→ 性能分析→ 自动化→ 云与容器网络→ 选定深耕方向
实践任务：完整排查一个真实故障（例如「某台机器能 ping 通但打不开网页」），写出从现象到根因的推理过程；再用 Python 写一个批量配置多台交换机的脚本。
